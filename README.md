# Burger-Restaurant-Menu
Smash The Hunger - Restaurant Menu Page
A sleek and responsive menu web page designed for a burger restaurant. The project allows users to explore various menu items, customize their orders by selecting sizes and side additions, and specify quantities through an intuitive interface. Built with a modern dark theme and bold accent colors to provide an engaging user experience.
Technologies Used: HTML5, CSS3.

واجهة إلكترونية حديثة لمطعم، مُصممة لعرض قائمة المأكولات الخفيفة بشكل جذاب والتفاعل مع طلبات المستخدمين. يتيح المشروع للزوار تصفح أصناف البرجر المختلفة، اختيار الأحجام والإضافات المتاحة، وتحديد الكميات المطلوبة بسهولة ويسر. تم التركيز في التصميم على استخدام ألوان متناسقة وهيكلية واضحة لتوفير تجربة مستخدم بسيطة وممتعة.
التقنيات المستخدمة: HTML5, CSS3.
